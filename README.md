# 🌱 Hydroponic Lettuce Yield Optimization: Advanced Sensor Analytics

An end-to-end Business Intelligence solution designed to transform raw IoT micro-climate telemetry into actionable crop health, environmental alert, and harvest planning insights for hydroponic farm operations.



## 📌 Executive Summary

Hydroponic crops are highly sensitive to micro-climate variations and water chemistry. Minor fluctuations in temperature or pH levels can stall plant development, burn leaves, or delay harvest schedules—directly impacting profitability.

This Power BI project shifts smart agriculture analytics from basic passive monitoring to proactive operational decision-making.

---

## 🎯 Key Questions Answered

* **Harvest Logistics:** Exactly what volume of the crop is harvest-ready?  
  * *Insight:* **36% (1,139 plants)** have reached the **Mature Stage** and are ready for harvest scheduling.
* **Environmental Risk Detection:** Were there micro-climate shocks during the monitoring window?  
  * *Insight:* Temperature dips down to **21°C** were detected on Sept 10th, triggering immediate monitoring for Mid-Stage plants to prevent growth delays.
* **Water Chemistry Compliance:** Are key chemical parameters balanced across active batches?  
  * *Insight:* **92%** of readings maintain optimal target levels (pH 6.0–6.6), with an average TDS of **598.05 ppm**.

## 🛠️ Tech Stack & Methods

* **Business Intelligence Tool:** Power BI (Desktop / Service)
* **Data Transformation:** Power Query / SQL / Python (Pandas)
* **Data Modeling:** Star Schema / DAX Custom Measures
* **Analytics Techniques:** Multivariable Cluster Analysis, Dynamic Text Callouts, Range Binning

---

## ⚙️ Key Technical Features

1. **Automated Insights Engine (DAX):**  
   Built dynamic text measures to summarize current crop health, alert growers to severe parameter dips, and recommend immediate operational actions.
   
2. **Multivariable Cluster Scatter Plot:**  
   Correlated ambient temperature and pH levels against plant maturity stages to map the optimal climate window for maximum yield rate.

3. **User-Centric Visual Architecture:**  
   Applied lightweight UI design principles, establishing standard card container styling, chronological lifecycle color mapping, and distinct KPI visual hierarchy.
